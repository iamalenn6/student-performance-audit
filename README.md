# Первичный аудит данных: Student Performance

Проект содержит воспроизводимый Jupyter Notebook для первичного аудита датасета **Student Performance Multiple Linear Regression**.

## Источник данных
Скачайте `Student_Performance.csv` со страницы Kaggle:
https://www.kaggle.com/datasets/nikhil7280/student-performance-multiple-linear-regression

Положите CSV в корневую папку проекта рядом с `audit.ipynb`.

## Что проверяется
1. Общая статистика и профиль исходной таблицы.
2. Пропуски и их заполнение: числовые — медианой, категориальные — модой.
3. Дубликаты и удаление полных дубликатов строк.
4. Константные и почти константные признаки.
5. Распределение `Performance Index`; квантильные интервалы как вспомогательная диагностика распределения регрессионной цели.
6. Статистики и графики распределений числовых признаков.
7. Boxplot и оценка потенциальных выбросов по правилу 1.5 IQR.
8. Итоговый профиль таблицы и сохранение очищенных данных.

## Запуск
```bash
python -m pip install -r requirements.txt
jupyter notebook audit.ipynb
```
Выполните ячейки сверху вниз. Ноутбук создаст `Student_Performance_cleaned.csv`, `data_profile.csv` и `outlier_summary.csv`.

## Важные оговорки
- В описании выбранного проекта указаны 10 000 строк и 6 столбцов; ноутбук проверяет это на фактическом CSV.
- `Performance Index` — числовая целевая переменная регрессии, а не изначальная категориальная метка. Квантильные интервалы используются только для диагностической оценки распределения.
- IQR отмечает потенциальные выбросы, но не доказывает ошибочность значения. Не удаляйте их без предметного обоснования.
- Способ заполнения пропусков — базовый вариант для первичного аудита; для моделирования имputation следует обучать только на train-части данных.
